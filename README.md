### 模型使用说明

通过仓库顶部 **Code → Download ZIP** 下载完整作品集并解压。打开 CATIA 装配文件时，请保留模型目录中的原始文件名和相对位置，以便查找零件引用。STEP 文件可使用支持该格式的 CAD 软件打开。
